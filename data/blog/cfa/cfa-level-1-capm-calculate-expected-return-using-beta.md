## Concept Explanation & Institutional Framework

From first principles, Security Market Line (SML) geometry, computing CAPM required return from Beta, identifying undervalued (above SML) vs overvalued (below SML) securities via Jensen's Alpha links theoretical valuation and risk mechanics to practical decisions in Portfolio Management. Security Market Line (SML) Required Return (E(R_i)_CAPM = R_F + β_i × [E(R_M) − R_F] where β_i = Cov(R_i, R_M) / σ_M^2 = ρ_{i,M} × (σ_i / σ_M)) establishes the primary relationship (Plots required return as a linear function of systematic risk β_i with intercept R_F and slope equal to the Market Risk Premium [E(R_M) − R_F].), while Jensen's Alpha & SML Valuation Rule (α_i = Forecasted Return E(R_i)_Analyst − Required Return E(R_i)_CAPM) governs If α_i > 0, the security plots ABOVE the SML and is UNDERVALUED (Buy); if α_i < 0, the security plots BELOW the SML and is OVERVALUED (Sell/Short).

## Core Formulas & Mathematical Equations

> [!NOTE]
> The following analytical equations govern problem-solving and numerical questions across this curriculum reading.

### Formula 1: Security Market Line (SML) Required Return

```formula
E(R_i)_CAPM = R_F + β_i × [E(R_M) − R_F] where β_i = Cov(R_i, R_M) / σ_M^2 = ρ_{i,M} × (σ_i / σ_M)
```

**Institutional Context & Variable Breakdown:** Plots required return as a linear function of systematic risk β_i with intercept R_F and slope equal to the Market Risk Premium [E(R_M) − R_F].

### Formula 2: Jensen's Alpha & SML Valuation Rule

```formula
α_i = Forecasted Return E(R_i)_Analyst − Required Return E(R_i)_CAPM
```

**Institutional Context & Variable Breakdown:**

- If α_i > 0, the security plots ABOVE the SML and is UNDERVALUED (Buy).

- if α_i < 0, the security plots BELOW the SML and is OVERVALUED (Sell/Short).

## Step-by-Step Worked Numerical Examples

### Worked Example 1: Evaluating Three Stocks Against the Security Market Line (SML)

**Problem & Given Scenario:**
The risk-free rate is R_F = 4.0% and the Expected Market Return is E(R_M) = 10.0% (Market Risk Premium = 6.0%). Evaluate: Stock A (β = 0.80, Analyst Forecast Return = 9.5%); Stock B (β = 1.20, Analyst Forecast Return = 11.2%); Stock C (β = 1.50, Analyst Forecast Return = 11.8%).

```formula
E(R_i)_CAPM = R_F + β_i × [E(R_M) − R_F] where β_i = Cov(R_i, R_M) / σ_M^2 = ρ_{i,M} × (σ_i / σ_M)
```

**Step-by-Step Substitution & Calculation:**

- **Step 1. Stock A: CAPM Required = 4.0% + 0.80(6.0%) = 8.80%. Since Forecast (9.50%) > Required (8.80%), Alpha α_A = +0.70% -> Plots ABOVE the SML -> UNDERVALUED (Buy).**

- **Step 2. Stock B: CAPM Required = 4.0% + 1.20(6.0%) = 11.20%. Forecast = 11.20%, Alpha α_B = 0.00% -> Plots ON the SML -> FAIRLY VALUED.**

- **Step 3. Stock C: CAPM Required = 4.0% + 1.50(6.0%) = 13.00%. Since Forecast (11.80%) < Required (13.00%), Alpha α_C = −1.20% -> Plots BELOW the SML -> OVERVALUED (Sell).**

> [!TIP]
> **Financial Interpretation & Exam Takeaway:**
> Don't fall for the visual trap: plotting ABOVE the SML means the expected return is HIGH (because current price P_0 is LOW), so the stock is UNDERVALUED!

### Worked Example 2: Connecting SML Return Alpha to Intrinsic Price Mispricing

**Problem & Given Scenario:**
Stock D currently trades at P_0 = $50.00, is expected to pay a Year-1 dividend of D_1 = $2.00, and has an analyst Year-1 price target of P_1 = $56.00. Its beta is 1.00 (so CAPM required return = 4.0% + 1.0(6.0%) = 10.0%).

```formula
α_i = Forecasted Return E(R_i)_Analyst − Required Return E(R_i)_CAPM
```

**Step-by-Step Substitution & Calculation:**

Analyst Forecast Holding Period Return = ($56.00 − $50.00 + $2.00) / $50.00 = $8.00 / $50.00 = 16.00%. Jensen's Alpha = 16.00% − 10.00% = +6.00% (plots above SML). Intrinsic Value V_0 = ($56.00 + $2.00) / 1.10 = $58.00 / 1.10 = $52.73 (> $50.00 market price!).

> [!TIP]
> **Financial Interpretation & Exam Takeaway:**
> As investors buy the undervalued stock (pushing P_0 up from $50.00 to $52.73), its expected return falls from 16.00% down to 10.00%, moving the stock back down onto the SML.

## Comparison & Reference Analysis

| Position Relative to SML | Forecast Return vs. CAPM Required | Jensen's Alpha (α_i) | Price Mispricing & Trading Action |
|---|---|---|---|
| Plots ABOVE the SML | Forecast E(R) > CAPM Required | Positive (α_i > 0) | Undervalued (V_0 > P_0) -> BUY |
| Plots ON the SML | Forecast E(R) = CAPM Required | Zero (α_i = 0) | Fairly Priced (V_0 = P_0) -> HOLD |
| Plots BELOW the SML | Forecast E(R) < CAPM Required | Negative (α_i < 0) | Overvalued (V_0 < P_0) -> SELL / SHORT |
| Market Portfolio (β = 1.0) | E(R_M) = R_F + 1.0 × ERP | Zero by definition | Anchor point of the SML |

## CFA Practice Questions & Detailed Solutions

### Practice Question 1

**Question:** A stock has a correlation with the market portfolio of +0.60, a standard deviation of 25.0%, and the market portfolio has a standard deviation of 15.0%. If the risk-free rate is 3.5% and the expected return on the market portfolio is 9.5%, the stock's CAPM required return is:

- **[A]** 9.50%

- **[B]** 10.00%

- **[C]** 13.50%

> [!TIP]
> **Correct Answer: Option A.**
>
> **Explanation:** First compute Beta: β_i = ρ_{i,M} × (σ_i / σ_M) = 0.60 × (25.0% / 15.0%) = 1.00. With β = 1.00, CAPM required return equals the expected market return E(R_M) = 3.5% + 1.00(9.5% − 3.5%) = 9.50%.

### Practice Question 2

**Question:** An analyst plots a security on the Security Market Line (SML) graph and finds that it lies strictly ABOVE the SML. This indicates that the security's:

- **[A]** Current market price is too high (overvalued) and its expected return is too low

- **[B]** Expected return exceeds its CAPM required return (positive Jensen's alpha), meaning the security is undervalued and is a Buy candidate

- **[C]** Unsystematic risk is negative

> [!TIP]
> **Correct Answer: Option B.**
>
> **Explanation:** The vertical axis of the SML is Expected Return. Plotting above the SML means the security's expected return is higher than required for its beta, which happens when its current market price P_0 is below intrinsic value V_0 (undervalued).

### Practice Question 3

**Question:** Unlike the Capital Market Line (CML), which applies only to efficient portfolios on the efficient frontier, the Security Market Line (SML) applies to:

- **[A]** Only risk-free government bonds

- **[B]** All individual securities and all portfolios (whether efficient or inefficient), because its horizontal axis measures only systematic risk (Beta)

- **[C]** Only 100% equity portfolios

> [!TIP]
> **Correct Answer: Option B.**
>
> **Explanation:** Because the SML prices only systematic risk (Beta), every asset and portfolio—efficient or inefficient—must lie on the SML in CAPM equilibrium.
